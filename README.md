# Retail Data Warehouse Dashboard

## Project Overview

This project demonstrates the design and development of a Retail Data Warehouse Dashboard using Power BI.

The dashboard provides insights into:

- Sales Performance
- Product Performance
- Customer Analysis
- Returns & Profitability

---

## Tools Used

- SQL
- Power BI
- DAX
- Figma
